# PS5_RetroArch-v4.7.0-beta-4

**Four fixes from your reports, and achievements now make a sound.**

<img src="https://raw.githubusercontent.com/mihawk-99/PS5_RetroArch/main/assets/readme/important-warning.png" alt="Important warning">

## PS5 RetroArch is a passion project, not a piracy project.

It exists so you can play the games you own on the console you own.

- **Piracy is not condoned.**
- **No games, BIOS files, console firmware or decryption keys are included, and they never will be.**
- **Use only legally obtained backups of games you own**, made yourself from your own discs, cartridges or digital purchases.
- **Use only BIOS and firmware files dumped from hardware you own.**
- **Requests for, or links to, games, BIOS files, firmware or keys are not welcome** in this project's issues or discussions.

<a id="library"></a>

## <img src="https://raw.githubusercontent.com/mihawk-99/PS5_RetroArch/main/webui/assets/fluent/library.svg" width="26" height="26" alt=""> Large libraries in the WebUI

- **"signal timed out" on every page.** With a very large library the WebUI's pages gave up waiting: for every game, the console looked for each kind of artwork under each file type, up to 80 checks a game.
- **Now each artwork folder is read once.** On a Base PS5 with 15,283 games the library's answer went from 10.8 seconds to 0.93, and it is the same answer.

<a id="settings"></a>

## <img src="https://raw.githubusercontent.com/mihawk-99/PS5_RetroArch/main/webui/assets/fluent/settings.svg" width="26" height="26" alt=""> WebUI settings stop overriding the menu

- **What happened.** A setting saved from the WebUI was applied again at every start. If the WebUI's volume slider had ever been moved, that volume came back each time, whatever you set in RetroArch's menu or in `retroarch.cfg`.
- **Now it is applied once.** At the next start the value becomes RetroArch's own setting, and a later change on the console stays. This goes for every setting the WebUI saves.

<a id="sounds"></a>

## <img src="https://raw.githubusercontent.com/mihawk-99/PS5_RetroArch/main/webui/assets/fluent/headphones.svg" width="26" height="26" alt=""> Sounds

- **The achievement unlock sound.** No release carried RetroArch's sound files, so an unlocked achievement was silent. They are included now, and the unlock sound is **on by default**; a config from an earlier release is switched on once when you update.
- **To turn it off:** Settings → Achievements → Appearance → Unlock Sound.
- **Menu sounds** (OK, cancel, music, scrolling) are included and stay off unless you turn them on: Settings → Audio → Menu Sounds.

<a id="dosbox"></a>

## <img src="https://raw.githubusercontent.com/mihawk-99/PS5_RetroArch/main/webui/assets/fluent/cloud.svg" width="26" height="26" alt=""> DOSBox Pure on a share

- **A DOS game's zip on an SMB share starts.** DOSBox Pure answered "No executable file found": it could not open a file on a share by itself, and no copy was made for it. The zip is now copied to the console for the session and removed when the game closes.
- **Not yet:** a ScummVM game kept as a folder on a share. Only the one chosen file is copied.

<a id="tested"></a>

## <img src="https://raw.githubusercontent.com/mihawk-99/PS5_RetroArch/main/webui/assets/fluent/checkmark-circle.svg" width="26" height="26" alt=""> Played on a Base PS5

| What | How it went |
| --- | --- |
| **Large library** | 15,283 games: 10.8 s on v4.6.0-beta-4, 0.93 s on this release, the same bytes. |
| **WebUI settings** | A volume saved from the WebUI moved into RetroArch's settings at the start and changed nothing else; set back to 0 on the console, it stayed 0 at the next start. |
| **DOSBox Pure on a share** | On v4.6: "Unable to open ZIP file". On this release the zip was copied, the program ran, and the copy was gone after closing. |
| **Sounds** | With every sound on, the menu ran without a crash and sound was produced. Nobody listened: please say if an unlock is silent for you. |
| **Controller remaps** | Checked for two older reports: a button remapped to another works, and so does a swap of two, on the NES core and on Dolphin. |

<a id="upgrading"></a>

## <img src="https://raw.githubusercontent.com/mihawk-99/PS5_RetroArch/main/webui/assets/fluent/arrow-sync.svg" width="26" height="26" alt=""> Upgrading from v4.6.0-beta-4

1. **Back up your existing title folder**, especially configuration, saves, states, system files, content and any custom media.
2. **Use the WebUI's Update button** (it works from v4.6.0-beta-4 on), or merge the complete `PPSA99169` folder from the package into your installation, keeping your own files and configuration.
3. Fully close and reopen PS5 RetroArch.

**No games, BIOS files, console firmware, or decryption keys are supplied. Use only legally obtained backups of games you own and system files dumped from hardware you own.**
