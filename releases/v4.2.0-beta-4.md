It exists so you can play the games you own on the console you own.

- **Piracy is not condoned.**
- **No games, BIOS files, console firmware or decryption keys are included, and they never will be.**
- **Use only legally obtained backups of games you own**, made yourself from your own discs, cartridges or digital purchases.
- **Use only BIOS and firmware files dumped from hardware you own.**
- **Requests for, or links to, games, BIOS files, firmware or keys are not welcome** in this project's issues or discussions.

<a id="driver"></a>

## <img src="https://raw.githubusercontent.com/mihawk-99/PS5_RetroArch/main/webui/assets/fluent/video.svg" width="26" height="26" alt=""> Graphics driver

The cores that draw with Vulkan (PPSSPP, Dolphin, Flycast, Mupen64Plus-Next, Azahar, Beetle PSX HW, SwanStation and PS5SX2) run on RADV, the Vulkan driver this project ports to the PS5. This release moves it forward:

- **Large buffers fit when memory is fragmented.** A buffer can now be made from several pieces of free video memory when no single piece is big enough.
- **Freed memory is not reused too early.** A buffer's memory stays reserved until the GPU has finished the work that used it.
- **Memory is counted correctly.** The driver reports every free range as available, and counts its own memory once.
- **Less memory set aside.** The mesh shaders' scratch area is 128 MiB instead of 320 MiB.
- **A cached pipeline that lost a stage is rebuilt** instead of used, and the driver adds `VK_KHR_fragment_shader_barycentric`.

<a id="sdk"></a>

## <img src="https://raw.githubusercontent.com/mihawk-99/PS5_RetroArch/main/webui/assets/fluent/settings.svg" width="26" height="26" alt=""> SDK

- **Upstream's v0.45 release.** The title and its cores are built with the payload SDK's v0.45 release.
- **The title's heap gives memory back.** Memory left free after a burst of allocations is returned, wherever it lies, and the heap grows in 2 MiB steps.

<a id="pcfx"></a>

## <img src="https://raw.githubusercontent.com/mihawk-99/PS5_RetroArch/main/webui/assets/fluent/content-view.svg" width="26" height="26" alt=""> PC-FX

- **A missing disc image no longer closes RetroArch.** The PC-FX core read a disc image that was not there as a file of impossible size and crashed. It now says it could not open the disc image, and RetroArch reports that the content failed to load. v4.1.0-beta-4 has the same crash.

<a id="upgrading"></a>

## <img src="https://raw.githubusercontent.com/mihawk-99/PS5_RetroArch/main/webui/assets/fluent/arrow-sync.svg" width="26" height="26" alt=""> Upgrading from v4.1.0-beta-4

1. **Back up your existing title folder**, especially configuration, saves, states, system files, content and any custom media.
2. **Use the WebUI's Update button**, or merge the complete `PPSA99169` folder from the package into your installation, keeping your own files and configuration.
3. Fully close and reopen PS5 RetroArch.

**No games, BIOS files, console firmware, or decryption keys are supplied. Use only legally obtained backups of games you own and system files dumped from hardware you own.**
